## 🔄 지금 진행 중인 것 (외부 대기)

IT 담당자에게 이미 전달한 DNS 레코드 등록을 기다리는 중입니다.

1. **`A cs.aicom.ac.kr` → `76.76.21.21`** (사이트 커스텀 도메인용)
2. **`mail.aicom.ac.kr` TXT/MX 레코드 4개** (이메일 발송 도메인 인증용, `docs/배포가이드.md` 4-1절)

→ 등록되면 알려주시면 제가 확인 후 마무리 설정(EMAIL_FROM 변경 등)까지 진행합니다.

## 🎯 정식 배포까지 남은 것

DNS 두 건을 빼면, 전부 **사용자님이 정보만 주시면 제가 바로 반영 가능한** 항목입니다.

| # | 항목 | 필요한 것 | 소요 |
|---|---|---|---|
| 1 | 회원가입 학교 이메일 제한 켜기 | 학교 이메일 도메인 (예: `xxx.ac.kr`) | 1분 |
| 2 | 개인정보 보호책임자 표기 | 담당자 이름 · 연락처 | 5분 |
| 3 | 이용약관/개인정보처리방침 확정 | 학과 검토 결과 (통과 여부) | 즉시 (배너만 제거) |
| 4 | 첫 관리자 계정 | 관리자로 쓸 이메일로 사이트에서 회원가입 1회 | 1분 |
| 5 | DNS 반영 확인 | IT 담당자 작업 완료 | 대기 (담당자 일정에 달림) |

**즉, 1~4번 정보를 한 번에 주시면 그날 안에 "정식 오픈 가능" 상태로 만들 수 있습니다.**
5번(DNS)만 온전히 사용자님 통제 밖의 대기 시간입니다.
