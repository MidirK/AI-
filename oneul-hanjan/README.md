# 오늘 한잔 (초기 프로토타입)

양주(위스키·브랜디·럼·진·보드카)가 낯선 사람도 편하게 술을 고르고, 마시는 방법을 알아보고, 어울리는
안주를 선택할 수 있도록 돕는 웹 서비스 프로토타입입니다.

이번 버전은 AI 모델, 강화학습, 로그인, 결제, 외부 API, 백엔드 없이 **정적 프런트엔드 + 로컬
데이터 + localStorage**만으로 동작합니다.

## 기술 스택

- React 18 + TypeScript + Vite
- Tailwind CSS
- React Router (클라이언트 라우팅)
- 저장/피드백: `localStorage`
- 추천 데이터: `src/data/*.ts` (로컬 정적 파일)

## 실행 방법

### GitHub Codespaces로 실행 (추천)

1. GitHub에서 이 저장소(`claude/quirky-fermi-fki0wj` 브랜치) 페이지의 **Code → Codespaces →
   Create codespace on claude/quirky-fermi-fki0wj** 클릭
2. Codespace가 열리면 (devcontainer가 자동으로 Node.js를 설치하고 `oneul-hanjan`에 `npm install`까지
   끝내둡니다) 터미널에서:
   ```bash
   cd oneul-hanjan
   npm run dev
   ```
3. "포트 5173로 포워딩됨" 알림이 뜨면 그 링크를 눌러 브라우저에서 확인
4. 데스크톱 VS Code에서 이어서 작업하고 싶다면: 우측 상단 `...` 메뉴 또는 `Codespaces: Open in VS
   Code Desktop` 명령으로 로컬 VS Code(Remote - Codespaces 확장 필요)에 연결하면 됩니다. 코드는
   클라우드에서 실행되고, 편집·터미널·포트 포워딩은 그대로 데스크톱 화면에서 쓸 수 있어요.

### 로컬 컴퓨터에서 실행

```bash
git clone -b claude/quirky-fermi-fki0wj https://github.com/MidirK/AI-.git
cd AI-/oneul-hanjan
npm install
npm run dev       # http://localhost:5173 에서 확인
```

빌드 확인:

```bash
npm run build      # tsc -b && vite build
npm run preview     # 빌드 결과 로컬 미리보기
```

## 구현된 기능

- **홈**: 헤드라인 문구, "술부터 고르기" / "안주부터 고르기" 시작 버튼, 양주 5종 카드, 오늘의 추천
  조합(데이터 내 고득점 페어링), 초보자를 위한 짧은 설명
- **술부터 고르기**: 술 종류 → 취향(달콤/산뜻/묵직) → 예산·조리시간·직접만들기/간편식 선택 →
  조건에 맞는 안주 최대 3개 추천. 결과가 없으면 예산·조리시간 조건을 완화한 대안을 안내
- **안주부터 고르기**: 이름 검색 + 카테고리 선택(치즈/고기/해산물/과일/초콜릿/견과류/기타) →
  안주 선택 → 어울리는 양주 종류와 이유 표시. 검색 결과가 없으면 조건 변경 안내
- **술 상세**: 향·맛 요약, 스타일(변형)별 서로 다른 향·맛 설명, 실제 적용되는 음용 방법만 표시(니트/
  온더록스/트와이스업/하이볼/믹서 등), 전문 용어 설명, 잔 종류·얼음 여부·제조 순서, 비율은 예시임을 표시
- **조합 상세**: 어울리는 이유, 직접 만들기 안주는 재료·분량·순서·소요시간, 간편식은 준비·플레이팅
  방법, "이렇게 즐겨보세요"(온도·한입 크기·곁들임·비교 시음 팁), 예상 비용(예시 표시), 대체 가능한
  술/안주, 저장 버튼, 좋아요/별로예요 피드백(같은 값 재클릭 시 취소, 추천 점수에 소폭 반영)
- **저장한 조합**: 저장 목록 조회·삭제, 새로고침해도 유지, 빈 상태 안내

## 예시 데이터로 동작하는 부분 (실제 데이터 아님)

- 양주 5종 × 스타일(변형) 2~3종, 음용 방법
- 안주 16종 (치즈 3 · 고기 3 · 해산물 3 · 과일 2 · 초콜릿 3 · 견과류 1 · 기타 1)
- 페어링 데이터 약 48건 (추천 문구, 취향 태그, 시음 팁 모두 데이터 파일에 미리 작성됨)
- 가격·조리 시간은 전부 예시 값이며, 실제 매장 재고·실시간 가격·공식 제휴 정보가 아닙니다.

## 확인한 것 / 확인하지 못한 것

- ✅ `npm install`, `npm run build`(타입체크 포함) 성공 확인
- ✅ Playwright로 두 추천 흐름, 상세 조회, 저장/해제, 새로고침 후 저장 유지, 좋아요 피드백,
  검색 결과 없음 안내, 데스크톱/모바일(375px) 레이아웃을 실행 확인
- ⚠️ 다양한 실기기·브라우저(Safari, 구형 브라우저 등)에서의 교차 테스트는 하지 않았습니다.
- ⚠️ Google Fonts(Noto Serif KR / Noto Sans KR)는 CDN에서 불러오므로, 오프라인이거나 폰트 로드가
  차단된 환경에서는 시스템 기본 글꼴로 대체되어 보일 수 있습니다.

## 향후 확장을 위한 구조

매장 상품 연동, 배달 서비스 연결, 혼술 인플루언서 콘텐츠 등은 `src/data/*.ts`에 필드를 추가하거나
새 데이터 파일을 만들어 확장하도록 화면과 데이터를 분리해두었습니다. 이번 버전에는 연결되지 않는
버튼이나 가짜 제휴 표시를 넣지 않았습니다.
