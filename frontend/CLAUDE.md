# CLAUDE.md (frontend)

이 파일은 Claude Code가 `frontend/` 폴더에서 작업할 때 참고하는 가이드입니다.
전체 프로젝트 개요는 상위 `../CLAUDE.md` 참고.

## 기술 스택

- React + Vite

## 개발 실행

```
npm install
npm run dev
```

백엔드 API 서버는 기본적으로 `http://localhost:8000/api`에서 동작한다 (`../backend`, `../docs/api-spec.md` 참고).

## 코딩 컨벤션

- **식별자(변수명, 함수명, 클래스명 등)**: 영어로 작성
- **주석 및 문서**: 한국어로 작성
- **커뮤니케이션**: 한국어 사용
